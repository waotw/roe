# Importing from a feed

This tool is in the Admin under: 🛠️ → [Feed Imports](/admin/feed_imports/).

Roe can import your articles or a podcast from an existing feed. Paste an RSS or Atom feed URL, or an Apple Podcasts link. Items come in as drafts — episodes (with audio) as podcast posts, everything else as articles. Media stays where it is currently hosted for now; nothing is published until you review it.

## Importing a feed

1. Paste an RSS or Atom feed url (works with Apple Podcast Links as well) and click `PREVIEW FEED`
2. Review the summary and click `IMPORT AS DRAFTS`.

All articles and episodes are imported as drafts so that you can review them before they're published.

## View and delete previous imports

You can delete all posts that are imported from any import by clicking `DELETE` on the Feed Imports page. Click on an Import's number to see the details and delete.
