subtitle: A GUID (Globally Unique Identifier) is a unique string of characters assigned to each item in an RSS feed. It allows podcast apps to identify episodes and prevent duplicate downloads.
excerpt: The GUID is a critical, though invisible, part of an RSS feed. It looks like a random string of numbers and letters. Its job is to tell podcast apps, 'This is a specific episode.' If a podcaster changes the title or description of an episode, the app knows it's still the same episode because the GUID hasn't changed.
