# Importing media

This tool is in the Admin under: 🛠️ → [Feed Imports](/admin/media_imports/).

Roe can import all media referenced from external sources and move it into your `site/media/` folder.

## Importing media

1. Choose what to import (Images, Audio, Video)
2. Click `IMPORT SELECTED`

All new media files will show up on the [Media](/admin/medium/browse) page. You can filter by `ALL` and use the sort for `Uploaded date (newest first)` which will show you all the media that was just imported.
