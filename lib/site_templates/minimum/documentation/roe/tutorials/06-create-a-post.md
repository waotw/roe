# How to Create a Post

1. Open Roe's [Admin](/admin)
2. Select Posts
3. Click `NEW POST` (link on the right)
4. Click `PREVIEW` → Roe opens a live preview in a new browser tab.
5. Arrange your windows so you can see both the editor and the preview at the same time.
6. Set the status to `published` to see this post show up in the collection from the previous tutorial.
