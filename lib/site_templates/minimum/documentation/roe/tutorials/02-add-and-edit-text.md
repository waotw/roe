# How to Add and Edit text

When editing a Page (or any content), you will see this set of buttons in the editor:

![The buttons in the Roe Editor](/media/images/roe-editor-buttons.png)

1. Start typing in the large text area
2. Select a word and click the **`B`** button
    - this will wrap the selected words in `**` on both sides.
3. Check the preview (click `PREVIEW` if you haven't) and you'll see that word is **bold**.
4. Now select a word and click the _`I`_ button, the preview will show this is _italic_.
5. Continue to try out various buttons and watch what happens in the preview.
6. Check out the next tutorial to add images.
