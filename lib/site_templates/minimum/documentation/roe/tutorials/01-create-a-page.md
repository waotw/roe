# How to Create a Page

1. Open Roe's [Admin](/admin)
2. Select Pages
3. Click `NEW PAGE` (link on the right)
4. Click `PREVIEW` → Roe opens a live preview in a new browser tab.
5. Arrange your windows so you can see both the editor and the preview at the same time.
6. Open the `Metadata [▶︎]` by clicking `▶︎`
    - change the `status` to `published`
    - click `+ Add field` and choose `collection`
    - Type `nav` into the `collection` field that was just added
    - Click `SAVE`
