# Edit your Tags

You can see all the tags you've used across Roe on this page.

- Clicking on the count will show you all the posts, pages, products or docs using that tag.
- You can rename a tag here and it will be renamed across all your files.
- Renaming one tag to another tag that already exists will merge them. If there are 2 posts with the tag `all-music` and 5 posts with the tag `music` and you rename `all-music` to `music`, there will now be 7 posts with the tag `music`.
- You can delete a tag here and it will be removed from all your files.
- You can create tags here, any unused tags will show a 0 count and there will be a mention of all unused tags under the table
- If you use the tag `music` on one post and then use `Music` on another post, these will be listed as individual tags. You can solve this by renaming `Music` to `music` which will make all posts using `Music` now use `music`.
